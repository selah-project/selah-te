# హీబ్రూ బైబిల్ — తెలుగు అనువాదం

హీబ్రూ గ్రంథం (తనఖ్) యొక్క వచనం-వచనం అనువాదం — మూల అక్షరాలకు
నమ్మకమైనది.

## హీబ్రూ మొదట

ఈ అనువాదం మిమ్మల్ని హీబ్రూ వరకు తీసుకెళ్ళడానికి ఉంది — దాని స్థానంలో
నిలబడటానికి కాదు. ఎల్లప్పుడూ చదవవలసినది హీబ్రూయే — దాని హల్లులు, దాని
అచ్చులు, దాని గుర్తులు. క్రింద ఉన్న తెలుగు ఒక కిటికీ, ప్రత్యామ్నాయం
కాదు. రెండూ వేరుపడిన ప్రతి చోటా, హీబ్రూయే సరైనది.

## నామం

నాలుగు అక్షరాల నామం కనిపించే ప్రతి చోటా మేము **యాహ్వే** అని
వ్రాస్తాము — దాన్ని బిరుదుతో మార్చము, సాధారణ పదంగా మార్చము.
**ప్రభువు** (బిరుదు — నామం కాదు), **యెహోవా** (సంకర రూపం), నామ-ఆసనంపై
**దేవుడు** — వీటిని వ్రాయము. నామం ఉన్నది ఉన్నట్లే నిలుస్తుంది, ప్రతి
చోటా — నామం ఎక్కడ ఉందో ఎల్లప్పుడూ కనబడేలా.

## అలెఫ్-తావ్ — ⟨את⟩

తెలుగు వాక్యంలో **⟨את⟩** భద్రపరచబడి కనిపిస్తుంది. హీబ్రూలో אֵת ఒక
చిన్న పదం, అది చేయబడిన దాన్ని సూచిస్తుంది; తెలుగులో దానికి సమానం
లేదు, చాలా అనువాదాలు దాన్ని నిశ్శబ్దంగా తొలగిస్తాయి. మేము దాన్ని
బ్రాకెట్లలో స్పష్టంగా ఉంచుతాము — అది భాషా నిర్మాణంలో భాగం కనుక.
తుడిచివేయడానికి బదులు, దాని ఉనికిని చూపించడాన్ని ఎంచుకున్నాము.

## ⟨బ్రాకెట్లలో⟩ ఉన్న పదాలు

ఇలా ⟨ఉన్న⟩ బ్రాకెట్లు **హీబ్రూలో లేని** పదాలను సూచిస్తాయి — తెలుగు
వాక్యం నిలబడటానికి అవసరమైన చేర్పులు. గుర్తు లేకుండా కలపడానికి బదులు
వాటిని బ్రాకెట్లలో ఉంచుతాము — మూల హీబ్రూ పదాలు, తెలుగు అవసరపు పదాలు
ఎల్లప్పుడూ వేరుగా కనబడేలా.

## నామాలు, బిరుదులు

దైవిక హీబ్రూ పదాలు — **ఎలోహీం**, **ఏల్**, **షద్దాయ్**, **అదోనాయ్**,
**యాహ్** — వాటి ధ్వనులతోనే వ్రాయబడ్డాయి; అన్నిటినీ ఒకే పదంలోకి
కుదించము. ప్రతిదానికీ దాని స్వంత బరువు ఉంది. వ్యక్తుల, స్థలాల నామాలూ
హీబ్రూ రూపం నుండే — అవ్రాహాం, యిత్సాక్, యాకోవ్, మోషే, యెరూషలాయిం.

## గుర్తు గల పదాలు

- **ఖెసెద్** (חֶסֶד) — నిబంధన నమ్మకమైన ప్రేమ. కేవలం "దయ" కాదు,
  కేవలం "ప్రేమ" కాదు; ఏ ఒక్క తెలుగు పదమూ దాన్ని మోయలేదు.
- **షెయోల్** (שְׁאוֹל) — హీబ్రూ చెప్పినట్లే మృతుల స్థలం; "నరకం" కాదు.
- **నెఫెష్**, **రూఅఖ్**, **కావోద్** — సందర్భాన్ని బట్టి (ప్రాణం లేదా
  జీవం, ఆత్మ లేదా గాలి, మహిమ లేదా బరువు) — ఒకే బిగుసుకున్న పదంతో
  కాదు.

## ప్రతి వచనం దాని స్వంత వెలుగులో

ప్రతి వచనం దాని స్థానంలో మాట్లాడుతున్నట్లే అనువదించబడుతుంది —
ఏక-ఎలోహీం హీబ్రూ విశ్వాసంలో చదవబడి, తరువాతి బోధ చేర్చకుండా, కథ
ముగింపు మొదట్లో చదవకుండా. పదాలు తమ స్థానంలో మోసే అర్థాన్ని అవి
మోయనివ్వడం — ఉద్దేశం అదే.

## ఫైళ్ళ అమరిక

ప్రతి వచనానికి ఒక ఫైలు: వచనం, దానితో పాటు పదం-పదం అర్థం హీబ్రూ
పక్కపక్కనే — ప్రతి హీబ్రూ పదాన్ని దాని తెలుగు జతతో ముఖాముఖిగా
చదవడానికి.
